# Amy Novel 发布说明

## v1.0.0（2026-08-31）

首个正式版。自 0.1.0 以来的主要变化：

- **可靠性闭环（AN-001～005）**：下一周期规划注入封存记忆（人物最新状态、开放
  伏笔、时间线尾部）；事实提案 payload 容错；单章审批硬门禁（候选接受只写正史，
  事实提案全部处理才放行下一章与周期封存）；规划 JSON 失败一次低温修复且原始与
  修复响应分别留痕；实体稳定短引用、限定名合并提案与跨周期提案去重。
- **Autopilot 全自动运行（AN-022）**：规划页第 10 步三档检查点（关键节点暂停 /
  每章暂停 / 全自动候选），Workflow Runner 复用规划器与批次执行器，断点恢复与
  批次状态收敛；已通过真实模型（GLM-5.2）autopilot 全流程评估。
- **Web 端长篇存储迁移 IndexedDB（AN-006）**：正文、版本、候选与事件不再受
  localStorage 5MB 配额限制，旧数据自动迁移。
- **安全加固（AN-012）**：全部写操作 IPC 参数运行时校验；Electron 窗口导航与
  新窗口策略；双端 CSP（Electron 渲染层零网络连接）。
- **开书体验**：篇幅顾问（番茄平台规则）、AI 简报起草、人物分层与人格阵容建议、
  文风模板库、单章审批、补写、事件日志与过期候选提示。
- **质量基线**：147 项自动化测试 + 双端 PlatformPort 契约套件 + Renderer 关键
  流程测试；`pnpm verify` 双端生产构建通过。

已知边界：未签名安装包（SmartScreen 提示）、无自动更新；“候选已生成但事实提案
为 0”暂无界面警示（AN-021 跟踪）。

## Windows 安装包

```bash
pnpm install
pnpm icons
pnpm build:win
```

安装包生成到 `release/`。当前发布目标为 Windows x64 NSIS，允许选择安装目录，并创建桌面和开始菜单快捷方式。

## 发布前检查

1. 运行 `pnpm typecheck` 与 `pnpm test`。
2. 运行 `pnpm build:web`，确认 Web 版本可构建。
3. 安装生成的 NSIS 包，验证新建作品、模型配置、批量生成和项目备份恢复。
4. 卸载默认保留用户数据；用户可先在“导出备份”中保存项目数据包。

## 当前边界

- 尚未配置代码签名，Windows 首次安装可能显示 SmartScreen 提示。
- 尚未接入自动更新；新版本通过重新下载安装包升级。
- API Key 存在当前 Windows 用户的 Electron safeStorage 文件中，不进入项目备份。
